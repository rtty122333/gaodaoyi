# 高岛易断 · Cardputer ADV 查询器

把《高岛易断》（高岛吞象 / Takashima Ekidan，明治时代公版文本）全文装进 Cardputer ADV，
开机进主菜单，两件事任选：

- **数字起卦占卜** —— 自己报 9 位数字（三组三位数），按傅佩荣《易经入门 17 讲》的数字卦法
  起出本卦 / 动爻 / 之卦，直接落到知识库里对应的断语上；
- **高岛易断原文** —— 按编号查任意一卦，逐层下钻到「全卦总论」或某一爻的详细占断解读。

中文在 1.14" 屏上实时渲染、可滚动。

## 开机流程
```
① 主菜单   1  数字起卦占卜
   │       2  高岛易断原文
   ├─ 选 1 → 数字输入（报 9 位）→ 起卦结果 ─ Enter ─┐
   └─ 选 2 → 选卦列表 ─ Enter ─┐                   │
                               ▼                   ▼
                          ② 详目（本卦 7 个条目，起卦时光标自动停在动爻）
                               │  Enter
                               ▼
                          ③ 正文（爻题 → 象传 → 高岛释义 → 占 → 占例），可滚动
```

## 三层浏览结构
```
① 选卦   64 卦编号 + 卦名列表（右侧画该卦六爻图形）
   │  Enter
   ▼
② 详目   标题行只显示本卦卦名（与右上角电量框同一行齐平）
   │      本卦 7 个条目，右侧卦象高亮当前那一爻
   │      条目名一行放不下时：仅"当前选中"那条缓慢平滑滚动，其余截断显示
   │      1 全卦总论      ← 卦名释义 / 卦辞 / 彖传 / 大象 / 总占
   │      2 初九 潜龙勿用
   │      3 九二 见龙在田，利见…   ← 未选中：截断 + 省略号
   │      ...
   │      7 上九 亢龙有悔
   │  Enter
   ▼
③ 正文   所选条目的完整解读（爻题 → 象传 → 高岛释义 → 占 → 占例），可滚动
```
层级命名：第②层叫「**详目**」——取「本卦详目」之意，即一卦之下的细目；
七个条目沿用易学原生的「全卦 + 六爻」叫法，爻名（初九/六二/上六…）本身就是最准确的目录名。

## 操作（键盘方向箭头是 `;` `,` `.` `/` 四键的第二功能）
| 界面 | 上下键 `;` `.` | 左右键 `,` `/` | Enter | 其它 |
|---|---|---|---|---|
| 主菜单 | 切选项 | 切选项 | 进入 | — |
| 数字输入 | — | — | 起卦（需输满 9 位） | `0-9` 输入、`del` 退格、`m` 回主菜单 |
| 起卦结果 | — | — | 看本卦（光标停在动爻） | `b` 看之卦、`r` 回去改数字、`m` 回主菜单 |
| 选卦 | 移动一行 | 翻一整页 | 打开所选卦 | 数字键输编号（1–64）、`m` 回主菜单 |
| 详目 | 切换条目 | **上一卦 / 下一卦** | 进入正文 | `m` 返回（哪来的回哪去） |
| 正文 | 滚动一行 | 翻一整页 | — | `m` 回详目 |

另：`n`/`p` 等价于 下/上 一行。

## 数字卦起卦（傅佩荣《易经入门 17 讲》随机数起卦法）
主菜单选「数字起卦占卜」，**自己报 9 位数字**（三组三位数，任意一位都可以是 0）：

| 组 | 输入 | 运算 | 结果 | 除尽时 |
|---|---|---|---|---|
| 第一组 | 第 1–3 位 | ÷ 8 取余 | **下卦**（内卦） | 记 8 → 坤 |
| 第二组 | 第 4–6 位 | ÷ 8 取余 | **上卦**（外卦） | 记 8 → 坤 |
| 第三组 | 第 7–9 位 | ÷ 6 取余 | **动爻**（变爻） | 记 6 → 上爻 |

余数对照**先天八卦数**：乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8。

> ⚠️ 两个最容易写错的地方：
> 1. **第一组是下卦，第二组才是上卦**（由下往上写），与常见"先上后下"的报数法相反；
> 2. 先天八卦数（乾 1…坤 8）**不是**代码里那套三爻 bit 值（乾 7、兑 3、离 5、震 1、
>    巽 6、坎 2、艮 4、坤 0），两套编号必须显式转换（`XT_BITS[9]`）。

### 关于「三位数」这条要求的松紧（本实现：放开）
傅佩荣原设定是**三组三位数**（首位非 0）。理由是：一位数、两位数的余数太容易心算，
"主观目的性非常强，那就不是问天意，而是看人意"；三位数要先做一次除法，随意性够高。
数字越小，取余越没有遮蔽作用：

| 这一组的值 | ÷ 8（下卦/上卦） | ÷ 6（动爻） |
|---|---|---|
| `004` = 4 | 余 4，**余数就是数字本身** | 余 4，同上 |
| `047` = 47 | 余 7，要算一下但能心算 | — |
| `431` | 商 53 余 7，必须列竖式 | — |

本实现按使用习惯**放开了首位 0 的限制**：9 位里任何一位都能填 0（含 `004`、甚至 `000000000`
→ 坤为地 上爻动）。代价就是上表第一行那种情况——结果可被一眼预判，随意性打折。
若要恢复严格模式，在 `inputAppend()` 里加回首位判断即可：

```cpp
if (digits.length() % 3 == 0 && c == '0') return;    // 每组首位非 0
```

（也因此三组数整体取模的分布是均匀的：八个余数各约 12.5%、六个动爻各约 16.7%；
实测 100 万次随机覆盖全部 64 卦。）

输入页**刻意不显示任何换算结果**（卦名 / 余数 / 爻位），只报「还需输入 N 位」——
边输边看到卦象会给报数者心理暗示，破坏"随意报数"的初衷；换算明细统一到起卦结果页才揭晓。

起卦结果页列出三组数的除法明细 + 本卦 + 动爻与之卦，右侧六爻图把**动爻标红**。
按 `Enter` 进本卦、`b` 进之卦，**光标都自动停在该动爻那一条上**——高岛断卦正是以动爻为重。
之卦由动爻阴阳互换得到（阳变阴、阴变阳），只在那一爻上变。
所以断卦看的就是「**本卦 + 动爻爻辞 + 之卦**」这三件套。

`_cast_check.py` 是这套换算的回归脚本：校验 64 卦六爻解析是 0..63 的双射、公开示例
（431/379/847 → 火山旅初爻；493/809/793 → 天风姤初爻；130/174/314 → 水泽节二爻）全部命中。

## 数据来源（最全公开版）
- 站点：`gaodaoyiduan.org/original/` 的 64 个卦页（每卦含卦名释义、卦辞、《彖传》《大象》、
  六爻逐爻的「高岛占断」与「占例」，并含乾/坤的「用九/用六」）。
- 抓取：64 页 HTML 存于 `raw/`；`_build.py` 把每卦正文按 `h3`（爻题）切成 **7 段**，
  生成 `src/gddy_data.h`（**1.55 MB，448 段**）。
- 正文元素语义（解析要点，**别漏**）：
  | 标签 | 含义 |
  |---|---|
  | `h2` | 卦名 |
  | `h3` | **爻题**（`初九: 潜龙勿用。`）—— 分段的锚点 |
  | `h4` | 小节标题（`占` / `占例`）→ 文中渲染成 `【占】` |
  | `p` | 正文段落 |
  | `blockquote.border-l-4` | 引文（卦辞 / 《彖传》/《大象》/《象传》） |
  | `ul > li` | **「占」下的问答条目**（`问战征：…`） |
  > 首版解析只抓了 `h2|h3|h4|p|b`，结果 `<blockquote>` 没匹配上（`<b\b` 不匹配 `<blockquote>`）、
  > `<li>` 完全没抓 —— 表现为**「占」下面的内容整段消失**。现已补齐这两类。
- 清洗：剔除站点排版残留（字间孤立空格、`［82］` 式校勘编号）。

## 中文显示（关键技巧）
- **M5GFX 库自带简体中文 efont 点阵字库**（`lgfx::fonts::efontCN_12/14/16/24`），
  直接 `setFont(&lgfx::fonts::efontCN_14)` 即可显示中文，**无需自己生成/外接字库**。
- 文本以 `const char*`（UTF-8）烧进 Flash，运行时按字数折行、分页滚动。
- 详目页行高在 `setup()` 里按 `fontHeight()` **实测**取值（并夹紧到 7 行刚好放得下），
  不写死，避免换字号后 7 行溢出屏幕。
- 详目条目名一行放不下时，**只有当前选中那条会滚**，其余条目静止截断成「前几字 + 省略号」。
- 滚动是**逐像素平滑滑动**（不是逐字跳跃）：把整名先画进一个 240×行高 的离屏缓冲
  （`LGFX_Sprite`），再按像素偏移从中切一条 `pushImage` 推上屏；节奏为
  **停 1.2s → 平滑滚到尾 → 停 0.9s → 平滑滚回 → 循环**，约 45px/s。
  位移时只重绘这一行，不整屏刷、不闪。缓冲分配失败会自动退化成静态截断显示。

## 工程文件
| 文件 | 说明 |
|---|---|
| `platformio.ini` | 本地 M5Stack 平台（`D:/cardputer/platform-m5stack`）+ `m5stack_cardputer` 板型 |
| `partitions.csv` | 8MB Flash 最大 app 分区（`max_app_8MB`，~7.9MB），突破默认 1.25MB 上限 |
| `src/main.cpp` | 主程序：主菜单 / 数字输入 / 起卦结果 / 三层视图、卦象绘制、电量显示 |
| `src/gddy_data.h` | 自动生成的 64 卦 × 7 段数据 |
| `_build.py` | **数据重建脚本**：`raw/*.html` → `src/gddy_data.h` |
| `_verify.py` | **数据校验脚本**：段数 / 标签 / 目录名宽度 / 正文非空 |
| `_cast_check.py` | **起卦换算回归脚本**：六爻解析双射性 + 三个公开示例 + 随机分布 |
| `raw/` | 64 卦原始 HTML（留档） |

## 构建与烧录
```bat
python D:/cardputer/gddy/_build.py        # 需要时重建数据
python D:/cardputer/gddy/_verify.py       # 校验数据(输出 _verify.out)
python D:/cardputer/gddy/_cast_check.py   # 校验数字卦换算(输出 _cast_check.out)
pio run -d D:/cardputer/gddy              # 编译  (Flash ~30%)
pio run -d D:/cardputer/gddy -t upload    # 烧录（插线；必要时按住侧面 G0/BOOT 进下载模式）
pio device monitor -b 115200              # 看串口
```
> 若日后 `pio platform update` 把框架升级、编译报 `pins_arduino.h` 缺失，跑一次
> `python D:/cardputer/fix_variant.py` 重注入 Cardputer 板型头文件。

## 备注
- 枚举成员**别取名 `INPUT`**：Arduino 的 `esp32-hal-gpio.h` 把它 `#define` 成 `0x01`（GPIO 方向宏），
  当枚举名会报 `expected identifier before numeric constant`。本项目的数字输入页枚举名为 `INPUT9`。
- 全本《高岛易断》体量很大（原书数百页），这里收录的是「每卦完整占断」级文本；若想进一步
  精简体积，可在 `_build.py` 里只保留卦辞 + 六爻断语、去掉「占例」。
- 想更新/扩充数据：替换 `raw/` 下 HTML 后重跑 `_build.py` 即可（结构变了就同步改 `_verify.py` 的断言）。
- 乾/坤两卦的「用九 / 用六」并入「上九 / 上六」段落尾部，不单独占条目（保持恒为 7 项）。
